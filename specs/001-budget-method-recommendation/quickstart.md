# Quickstart: проверка функции 001

Руководство по проверке, что функция работает от начала до конца. Детали — в
[data-model.md](data-model.md) и [contracts/](contracts/).

## Предварительные условия

- Node.js ≥ 22 (проверено на 26) и npm.
- Для проверки в Telegram: бот, созданный через @BotFather, и HTTPS-адрес, где опубликована
  сборка (или HTTPS-туннель к локальному dev-серверу).

## Установка и запуск

```bash
npm install
npm run dev          # Vite dev-сервер; вне Telegram используется режим хранения indexeddb
```

## Автоматические проверки

```bash
npm run typecheck    # tsc --noEmit, strict
npm run lint
npm test             # Vitest: домен, хранилище, импорт/экспорт
npm run test:e2e     # Playwright с моком window.Telegram.WebApp
# Без скачанных браузеров Playwright — через установленный Chrome:
# PowerShell: $env:PW_CHANNEL="chrome"; npm run test:e2e
```

Ожидаемо:

| Проверка | Что подтверждает |
|---|---|
| `tests/unit/scoring.spec.ts` | Эталоны E1–E4 из [scoring-rules-v1.md](contracts/scoring-rules-v1.md) — метод, альтернатива, факторы |
| `tests/unit/plans.spec.ts` | Эталоны E1, E2, E5, E6 — суммы до копейки, Σ частей = доход |
| `tests/unit/money.spec.ts` | Запрет сложения разных валют, округление, безопасные целые |
| `tests/integration/repository.spec.ts` | Шифрование, оба режима хранения, прерванная запись не портит данные, нет сетевых вызовов |
| `tests/integration/export-import.spec.ts` | Круговой экспорт/импорт, отклонение повреждённого файла без изменения данных |
| `tests/e2e/*.spec.ts` | Приёмочные сценарии US1–US3 из [spec.md](spec.md) |

## Ручная проверка в Telegram

1. В @BotFather: `/newbot`, затем Bot Settings → Menu Button → URL сборки.
2. Открыть бота в Telegram на телефоне, нажать кнопку меню.
3. Пройти анкету с профилем E1 (зарплата 120 000, обязательные 45 000, цель «подушка»,
   контроль «простой») → рекомендация «50/30/20», факторы начинаются с доли обязательных трат.
4. Принять → план: 60 000 / 36 000 / 24 000.
5. Закрыть и снова открыть Mini App → профиль и план на месте.
6. Настройки данных → Экспорт → файл сохранён. Удалить все данные → приложение пустое.
   Импортировать файл → данные восстановлены.
7. Повторить шаги 2–5 в Telegram Desktop и Telegram Web; записать, какой режим хранения
   выбран (показывается в «Настройки данных»).

## Критерии готовности

- Все автоматические проверки проходят.
- Ручная проверка пройдена на iOS или Android и на Telegram Desktop.
- В DevTools во вкладке Network нет запросов, кроме загрузки статики и `telegram-web-app.js`.
